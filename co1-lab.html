📦 What is a Variable?
💡 Definition
A variable is a name that points to a value stored in the computer's memory. Think of it as a sticky-note label on a box that holds something.
unit_price  ➜  45.50
💡 Key ideas
  • Create a variable by assignment: name = value
  • No declaration needed – Python decides the type from the value (dynamic typing)
  • A variable can be re-assigned to a new value at any time
  • Read = as “gets”, not “equals”: the right side is worked out first, then stored under the name on the left

🏷️ Naming Variables: Rules, Dos & Don'ts
💡 Rules Python enforces
  • Only letters, digits and underscore _
  • Cannot start with a digit
  • No spaces and no special symbols (such as - $ @)
  • Case-sensitive: price and Price are different variables
  • Cannot be a Python keyword (class, if, for ...)
✅ Do
  • Use snake_case: total_price
  • Choose meaningful names: gst_amount
  • Keep names short but readable
❌ Don't
  • 1st_item – starts with a digit
  • my price – contains a space
  • x, a1 – meaningless for business data
  • print, list, sum – hides Python's built-ins
⚠️ Exceptions (errors) you will meet
  • SyntaxError – illegal name such as class = 5
  • NameError – using a name that was never created (usually a typo or wrong capital letter)

🔄 Type Conversion (Casting)
💡 Convert one type into another
  • int(x)   float(x)   str(x)   bool(x)
  • Data from forms, files and input() arrives as text (str) – convert it before calculating
  • Falsy values: 0, "" (empty text), None. Almost everything else is True
✅ Do

  • Check with type() when unsure
  • Use round() when you need rounding
❌ Don't
  • int("abc") – ValueError
  • int("3.5") – also a ValueError! Use int(float("3.5"))
  • Expect int(7.9) to round – it cuts to 7

🚧 Operator Pitfalls: Dos, Don'ts & Exceptions
✅ Do
  • Use brackets to make the order clear: (a + b) * c
  • Remember / always gives a float, // gives a whole number
  • Use round(x, 2) to display money
  • Convert with str() before joining text and numbers
❌ Don't
  • Write if a = 5 – use ==
  • Rely on float equality: 0.1 + 0.2 == 0.3 is False!
  • Divide by zero
  • Add text and numbers: "Total: " + 500
⚠️ Exceptions (errors) you will meet
  • ZeroDivisionError – 10 / 0
  • TypeError – "Total: " + 500 (cannot add str and int)

💡 Definition
A list keeps many items in one variable, in order, inside square brackets [ ].
Index0123
