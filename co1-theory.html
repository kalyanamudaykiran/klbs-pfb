•== equal to, != not equal to

Logical operators

CO1 / COI1 · Basics and decisions

•and: True only if both sides are True

•or: True if at least one side is True

•not: flips True and False

•Combine them to write business rules

CO1 / COI1 / LECTURE 1 · CONDITIONALS

Making decisions with if

CO1 / COI1 · Basics and decisions

•if, elif and else choose one path

•A condition is either True or False

•Indent the block by 4 spaces and end the line with a colon

marks = 72

if marks >= 80:

   grade = "A"

elif marks >= 60:

   grade = "B"

else:

   grade = "C"

print(grade)

Output: B

Which structure should I use?

CO1 / COI2 · Data structures and loops

​

list [ ]

A series of values, such as daily sales

​

dict { }

CO1 / COI2 / LECTURE 2 · LOOPS (1 OF 2)

The for loop

CO1 / COI2 · Data structures and loops

•for walks through a collection, one item at a time

•The loop variable (p) holds the current item

•Indent the lines that should repeat

•Great for totals, counts and reports

prices = [120, 80, 45]

total = 0

for p in prices:

   total = total + p

print(total)

Output: 245

CO1 / COI2 / LECTURE 2 · LOOPS (2 OF 2)

The while loop

CO1 / COI2 · Data structures and loops

•while repeats as long as a condition is True

•Something inside the loop must change the condition

•Otherwise it never stops (press Ctrl+C)

•Use for for known collections, while for “until done”

stock = 3

while stock > 0:

   print("Selling...")

   stock = stock - 1

print("Sold out")

Output:

Selling...

Selling...

Selling...

Sold out

CO1 / COI3 / LECTURE 3 · FUNCTIONS

Functions: write once, use often

CO1 / COI3 · Functions and automation

•A function packages steps under a name

•def starts it, and return sends a value back

•Parameters can have default values

def add_gst(amount, rate=18):

   return amount * (1 + rate / 100)

print(add_gst(1000))

print(add_gst(1000, 5))

Output:

1180.0

1050.0

CO1 / COI3 / LECTURE 3 · CLEAN CODE

Four habits of readable code

CO1 / COI3 · Functions and automation

•Meaningful names: price_with_gst says what it does

•Small functions with one clear job

•Comments explain why, not what

•Consistent style: 4 spaces, snake_case (PEP 8)

# Why: the GST rate may change

GST_RATE = 0.18

def price_with_gst(price):

   return price * (1 + GST_RATE)

print(price_with_gst(1000))

Output: 1180.0
