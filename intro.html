INTRO / INTRO-1 · WHAT & HOW

What Python is — and how it works

•A high-level language: it reads far closer to English than to machine code

•Interpreted: Python executes your lines one by one — no compile step, instant feedback

•Runs anywhere: a browser notebook on day one, a script on your laptop, a job in the cloud later

1 · WRITE

Plain-English code in a notebook or .py file — you describe the work, no jargon

2 · RUN

Python executes it line by line and shows you each result as it goes

3 · USE

Tables, charts and automations — straight into the decision
